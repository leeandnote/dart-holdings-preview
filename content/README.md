# 시리즈 원고 운영

`notes/*.md`는 비공개 빌드 입력이며 Git에서도 제외됩니다. 사이트 폴더에 복사하지 않습니다.
공개 저장소에는 AES-256-GCM 암호화 묶음 `notes.enc.json`만 커밋합니다.
로컬 편집 후 `node private_notes.mjs --pack`으로 갱신하고 묶음만 커밋합니다.
복호화 키는 로컬 `.private/notes-archive-key`와 GitHub Secret `NOTES_ARCHIVE_KEY`에만 둡니다.
새 작업 환경에서는 이 키를 안전하게 전달받아 `node private_notes.mjs`로 복원합니다.
초안 편성표 자체는 발행 예약 완료가 아닙니다. 본문 작성, 품질 기준 충족,
사람의 사실 검수가 모두 완료되어야 공개됩니다.

## 검수와 예약

1. 본문과 frontmatter를 작성합니다. 원문 링크와 확인일을 `references`에 넣습니다.
2. 사람이 숫자, 날짜, 조문, 원문, 가상 예시 표기를 대조합니다.
3. `node check_note_queue.mjs --hashes`로 원고 지문을 확인합니다.
4. 사람 검수 결과만 `review.status: approved`, `review.reviewer`,
   `review.reviewed_at`(시간대 포함), `review.content_sha256`에 기록합니다.
   AI나 빌드 스크립트가 검수자를 대신하지 않습니다.
5. 검수 후 내용이나 예약 시각을 바꾸면 지문이 달라져 다시 보류됩니다.
   이미 시리즈로 발행한 원고를 미검수 상태로 바꾸면 배포 자체를 중단해
   기존 공개 버전이 이전 자동 생성 글로 되돌아가지 않도록 보호합니다.
   발행된 원고 수정은 새 검수까지 마친 뒤 암호화 묶음을 갱신합니다.

본문은 Markdown이며 도표는 `<figure>`와 캡션을, FAQ는
`<section data-faq><h3>질문?</h3><p>답변</p></section>`을 사용합니다.
`references` 항목은 `title`, HTTPS `url`, `checked_at: YYYY-MM-DD`입니다.
제도 노트에는 공식 법령/규정/기관 원문의 `quote`도 반드시 넣습니다.
표, 도표와 코드 블록을 제외한 공백 없는 글자 수로 분량을 검사합니다.
형식 검사는 원문의 사실 검증을 대체하지 않습니다.

큰손 노트는 서로 다른 DART 접수번호 10개 이상이 필요합니다.
용어 글은 `definition`과 실제 DART 사례 표가 있어야 합니다.
용어 짧은 정의 페이지와 본문은 양방향 연결됩니다.
`related_terms`에는 존재하는 용어 slug만 지정합니다.

## 기존 글과 첫 4주 편성

기존 11편은 이미 공개된 글이므로 최초 날짜와 URL을 유지합니다.
동일 slug의 재작성 원고가 미래 예약/미검수 상태이면 기존 공개 버전을 유지합니다.
새 글에 기존 시리즈 순번을 재사용할 수 없습니다.
첫 편성 원고 슬롯은 암호화 묶음 안에만 있습니다. 슬롯이 있어도 본문과 검수 승인이 필요합니다.

금요일 07:00 주간 글은 목요일까지 확인된 데이터만 포함합니다.
첫 주 금요일의 대상은 요청한 11월 마지막 주(11/23~11/29)입니다.
12/27 캘린더는 다음 주 12/28~1/3을 대상으로 합니다.
공개 예고 금지 원칙에 따라 12월 결산 예고는 공개하지 않습니다.

## 배포와 운영 알림

기존 `site-deploy.yml`에서 매일 22:00 UTC(다음 날 07:00 KST)에 실행합니다.
GitHub 예약 실행은 지연될 수 있으므로 초 단위 정시 발행을 보장하지 않습니다.
아침 배포는 공시 API 재수집 없이 기존 공개 글을 보존하고 시리즈를 갱신합니다.
평일 공시 수집/일간 SNS 발행 워크플로는 변경하지 않습니다.
수동 실행에서 `published_only: true`로 동일 경로를 실행할 수 있습니다.
검수된 원고가 없으면 글을 꾸며내거나 빈 글을 발행하지 않습니다.

운영 알림은 `TELEGRAM_BOT_TOKEN`과 **개인 대화 ID**인
`TELEGRAM_OPERATOR_CHAT_ID` GitHub Secrets를 사용합니다.
공개 채널 ID를 대체값으로 사용하지 않습니다. 개인 채팅에서 먼저 봇을 시작해야 합니다.
다음 날 원고가 없으면 로그 및 운영자 메시지로 알립니다.
다음 7일 원고 재고도 함께 기록합니다.
발행 후 기존 사이트맵/RSS/IndexNow 경로가 실행됩니다. IndexNow는 색인 보장이 아닙니다.
